# React Commerce Analytics Dashboard

A polished, responsive e-commerce analytics dashboard built as a compact frontend portfolio project.

## Features
- Responsive sidebar navigation
- KPI cards
- Revenue area chart
- Sales channel distribution chart
- Searchable recent orders table
- Top products section
- Date-range UI
- Responsive mobile layout

## Tech Stack
- React
- Vite
- Tailwind CSS
- Recharts
- Lucide React

## Run Locally
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build
```bash
npm run build
```

## Suggested GitHub Repository Name
`react-commerce-analytics-dashboard`

## Portfolio Description
A responsive e-commerce analytics dashboard built with React, Tailwind CSS and Recharts, featuring KPI cards, revenue visualization, order search and sales-channel analytics.
